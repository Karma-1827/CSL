# 附件：MPTS 封測帳號與分派名冊

> 此附件提供管理員分配封測帳號。這些帳號只供測試使用，不是正式使用者；密碼、安全問題答案與任何真實個資均不可寫入本文件。

正式測試網址：[https://mpts.tcsl.ntnu.edu.tw/](https://mpts.tcsl.ntnu.edu.tw/)

## 使用原則

- 所有測試資料、私訊、課程主題及佐證連結開頭請加上 `【封測】`。
- 尚未註冊者，請用本附件的「帳號」及「身份別」註冊，並自行設定測試密碼與三個不同的安全問題。
- Tutor 的學制在建立個人資料時選擇：一般 Tutor 選「碩士班」，馬里蘭計畫 Tutor 選「大學部」。
- 每位測試者都要完成操作指引中的共同清單，以及自己帳號角色的全部清單。
- 表格最後一欄只用來安排配對對象或特殊測試情境，不是個人的測試範圍。
- 標有搭配帳號的任務，請由管理員安排雙方在相近時間操作，避免邀請、配對或雙方確認時找不到對象。
- 若完成測試或忘記密碼，請回報管理員；不要把密碼傳到群組。
