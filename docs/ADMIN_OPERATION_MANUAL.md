# MPTS 管理員操作手冊

本手冊給 MPTS 管理員使用，內容包含名冊匯入、口語能力審核、配對管理、課程與補登查核、學期設定、資料匯出及系統紀錄等日常行政工作。

正式系統網址：[https://mpts.tcsl.ntnu.edu.tw/](https://mpts.tcsl.ntnu.edu.tw/)

---

## 一、使用前先了解

### 1.1 兩種管理介面

系統有兩個管理入口：

| 管理介面 | 主要用途 | 使用方式 |
| --- | --- | --- |
| MPTS 管理首頁 | 日常行政工作，例如審核、配對、課程、補登、匯出及名冊匯入 | 從正式系統首頁登入管理員帳號 |
| 系統管理後台 | 合作計畫、上課文件、帳號狀態、時數調整及特殊資料管理 | 須在校內網路或連上師大 VPN 後使用 |

日常工作以 MPTS 管理首頁為主。只有手冊中特別註明「進入系統管理後台」的項目，才需要使用第二個入口。

系統管理後台網址是 `https://mpts.tcsl.ntnu.edu.tw/system-admin/`，登入帳號密碼與 MPTS 管理首頁相同。這個後台只開放校內網路或連上師大 VPN 才能連線；如果還沒有 VPN 連線設定，請洽系統維運人員或學校資訊中心協助申請，本手冊不涵蓋 VPN 設定步驟。

### 1.2 管理員帳號注意事項

- 每位管理員使用自己的帳號，不要共用帳號或密碼。
- 離開座位或使用完畢後，請由右上角選單登出。
- 不要將名冊、資格文件、課堂佐證或匯出檔案傳到公開連結。
- 若看到不屬於業務範圍的個資，或懷疑帳號被他人使用，請立即登出並通知維運人員。
- 新增管理員帳號、重設管理員密碼及大量刪除資料，由維運人員處理，不在一般行政操作範圍內。

### 1.3 常見狀態

| 狀態 | 說明 |
| --- | --- |
| 待審核 | 資料已送出，尚未由管理員處理 |
| 通過／核准 | 資料符合規定，後續功能會依規則開放 |
| 補件／不核准 | 資料需要修正，畫面會保留管理員填寫的原因 |
| 已紀錄 | 管理員已查看並留下紀錄，不代表事件已完全解決 |
| 有效成立 | 雙方完成必要步驟；若屬補登，還須經管理員核准 |

## 二、登入與畫面導覽

### 2.1 登入管理員帳號

1. 開啟正式系統首頁。
2. 在「帳號」欄輸入管理員帳號。
3. 在「密碼」欄輸入密碼。
4. 按「登入」。
5. 登入成功後會進入「系統總覽」。

如果連續輸入錯誤密碼，系統會暫時限制登入。請先確認鍵盤大小寫及帳號，再聯絡維運人員，不要持續重試。

### 2.2 左側功能選單

管理首頁左側包含以下功能：

| 功能 | 用途 |
| --- | --- |
| 系統總覽 | 查看名冊、註冊、老師、學生、配對及邀請數量 |
| 口語能力審核 | 審核老師上傳的口語能力證明 |
| 配對管理 | 查看邀請、目前配對及建立管理員手動配對 |
| 解除審核 | 處理老師或學生提出的解除配對申請 |
| 課堂通報 | 查看上課當下送出的聯絡異常通報 |
| 異常回報 | 查看課後提出的場地、進度、行為或安全問題 |
| 補登審核 | 審核逾期補簽到及補課堂紀錄 |
| 學期設定 | 新增、編輯或移除學期期間設定 |
| 課程總覽 | 查看全系課程、時數及未完成狀態 |
| 資料匯出 | 依計畫、對象、期間及欄位下載資料 |
| 名冊匯入 | 匯入老師及學生學號與身分別 |
| 系統紀錄 | 查看近期註冊、審核及行政操作紀錄 |
| 學生名冊 | 搜尋、篩選及查看單一名冊資料 |

選單右側的數字代表目前待處理筆數。點選功能後，主畫面會切換到對應頁面。

### 2.3 登出

1. 點右上角的使用者名稱。
2. 選擇「登出」。
3. 確認畫面回到登入頁。

在公用電腦操作時，登出後也請關閉瀏覽器視窗。

## 三、系統總覽

### 3.1 查看統計卡片

登入後，系統總覽會顯示：

- 名冊人數
- 已註冊人數
- 老師人數
- 學生人數
- 輔導中的配對數
- 待回覆邀請數

部分卡片可以點擊。點擊後會進入對應名單或管理頁面，方便進一步查看資料。

### 3.2 數字與名冊不一致時

先確認以下情況：

1. 名冊是否已成功匯入。
2. 使用者是否已完成註冊及個人資料。
3. 名冊角色是否為老師或學生。
4. 帳號或名冊是否已停用。
5. 配對或邀請是否已結束、取消或過期。

若仍無法確認原因，請記下學號、畫面顯示數量及發生時間，再交由維運人員查核。

## 四、名冊匯入

### 4.1 快速匯入檔案格式

快速匯入適合只有「學號＋身分別」的名單。支援 `.xlsx` 及 `.csv`。

| 第一欄 | 第二欄 |
| --- | --- |
| 學號 | 身分別 |

第二欄可使用本地生、僑生、港澳生、陸生、外籍生或馬里蘭學生。系統會將馬里蘭學生歸為外籍生類別，實際配對範圍仍由「馬里蘭大學」合作計畫決定。

舊的單欄學號名單仍可匯入，但建議新名單都填寫身分別，避免註冊時無法核對。

### 4.2 匯入老師名冊

1. 點左側「名冊匯入」。
2. 找到老師適用的合作計畫卡片。
3. 在卡片內找到「Tutor 名單」。
4. 按「選擇檔案」，選取 `.xlsx` 或 `.csv`。
5. 按「匯入名冊」。
6. 查看頁面上方的匯入結果。

一般華語系老師請從「師大外籍生（NTNU）」卡片的 Tutor 名單匯入。這類老師在學生名冊的「所屬計畫」顯示空白是正常情況，系統仍會把他們納入可輔導 NTNU 學生的老師名單。

其他合作計畫的老師須從該計畫卡片匯入。只有列在該計畫 Tutor 名單中的老師，才能看到及配對該計畫的學生。

### 4.3 匯入學生名冊

1. 在「名冊匯入」找到學生所屬的合作計畫。
2. 在卡片內找到「Tutee 名單」。
3. 選擇學生名單檔案。
4. 按「匯入名冊」。
5. 查看新增、補上身分別、略過及錯誤筆數。

學生的所屬計畫會直接影響可配對老師、邀請方向、上課文件及時數證明內容，因此匯入前務必確認卡片正確。

### 4.4 重複匯入的處理方式

- 新學號：建立新名冊資料。
- 已存在且身分別空白：補上這次匯入的身分別。
- 已存在且身分別相同：略過，不重複建立。
- 已存在但身分別不同：保留系統原資料，並顯示提醒。
- 學號或身分別格式錯誤：略過該列並顯示列號及原因。

看到錯誤提醒時，請先修改原始檔案，再重新匯入。不要為了通過匯入而直接改動不確定的名冊資料。

### 4.5 進階匯入

進階匯入適合已準備姓名、角色、學制、身分別及計畫代碼的完整資料。

1. 在名冊匯入頁下方展開「進階匯入」。
2. 下載 CSV 或 Excel 範本。
3. 依範本欄位填寫，不要自行更改欄位名稱或順序。
4. 選擇完成的檔案。
5. 按「匯入名冊」。

下載的範本檔案已附 2 列範例資料，可直接對照著填寫。各欄位說明如下：

| 欄位名稱 | 內容 | 可填入的值 |
| --- | --- | --- |
| `student_id` | 學號 | 直接填學號 |
| `name_zh` | 中文姓名 | 直接填姓名，可留空 |
| `name_en` | 英文姓名 | 直接填姓名，可留空 |
| `role` | 角色 | `TUTOR`（老師）或 `TUTEE`（學生） |
| `education_level` | 學制 | `BACHELOR`（大學部）、`MASTER`（碩士班）、`DOCTORAL`（博士班）；學生或尚未確定學制請填 `NA` |
| `identity_category` | 身分別 | `LOCAL`（本地生）、`OVERSEAS`（僑生）、`HONG_KONG_MACAO`（港澳生）、`MAINLAND`（陸生）、`INTERNATIONAL`（外籍生） |
| `program_code` | 所屬合作計畫代碼 | 例如 `NTNU`、`MARYLAND`；不屬於任何計畫（例如一般華語系老師）請填 `NA` |
| `is_enabled` | 是否啟用 | `TRUE`（啟用）或 `FALSE`（停用） |

進階匯入採整批檢查。只要有資料列不符合規則，系統不會寫入整批資料，請依畫面列號修正後重新上傳。已存在的學號會略過，不會覆蓋原資料。

## 五、學生名冊與帳號資料

### 5.1 搜尋及篩選

1. 點左側「學生名冊」。
2. 在搜尋框輸入學號或姓名。
3. 可再使用右側篩選條件，依角色、學生類別、所屬計畫、學制、註冊狀態、帳號狀態或閒置狀態縮小名單。
4. 要恢復完整名單時，清除搜尋文字及篩選條件。

### 5.2 查看單一名冊資料

點學號後可查看該筆名冊的角色、身分別、學制、合作計畫、啟用狀態及註冊狀態。

修改前請先確認資料來源。名冊角色或合作計畫會影響註冊及配對權限，已註冊帳號若需更改這些欄位，建議先交由維運人員確認資料關聯。

### 5.3 查看行政檔案

在名冊清單點「查看檔案」，可開啟單一使用者的行政彙整頁。頁面包含：

- 基本資料
- 教學或學習資料
- 口語能力審核狀態
- 目前與歷史配對
- 各學期課程及時數
- 課堂通報
- 異常回報

此頁以查閱為主。需要審核或修改時，請回到左側對應功能，不要把行政彙整頁當成編輯頁使用。

### 5.4 停用及恢復帳號

帳號狀態須在系統管理後台處理：

1. 進入「使用者」名單。
2. 搜尋學號。
3. 開啟使用者資料。
4. 將帳號狀態改為「停用」或「啟用」。
5. 儲存。

停用後使用者不能登入，但歷史配對、課程、時數及訊息不會被刪除。恢復前請確認停用原因已處理。

## 六、合作計畫與上課文件

### 6.1 新增合作計畫

1. 進入「名冊匯入」。
2. 點「新增合作計畫」中的系統管理連結。
3. 填寫計畫代碼、中英文名稱、啟用狀態、邀請權限、學生證明下載權限及中英文證明文案。
4. 儲存。
5. 回到 MPTS 管理首頁的「名冊匯入」，確認新增的計畫卡片已出現。

計畫代碼建立後不建議更改。名稱、邀請方向及證明文案會直接顯示在使用者介面或下載文件中，儲存前請再次校對。

### 6.2 停用合作計畫

停用計畫不會刪除既有名冊、配對、課程或時數，但會影響後續名冊匯入與使用者可用功能。停用前請先確認：

- 計畫是否已結束。
- 是否仍有進行中的配對或未完成課程。
- 使用者是否還需要下載證明。
- 是否已完成資料匯出及備份。

### 6.3 上傳上課文件

上課文件適用於特定合作計畫的教材、課程說明或教師提供的檔案。

1. 進入系統管理後台的「上課文件」。
2. 新增文件名稱及檔案。
3. 選擇適用合作計畫。
4. 設為啟用後儲存。

適用計畫的老師及學生會在右上角使用者選單看到「上課文件」。停用文件後，選單及原下載網址都不再提供存取。

## 七、學期設定

### 7.1 新增學期

1. 點左側「學期設定」。
2. 展開「新增學期」。
3. 填寫中英文學期名稱、開始日、結束日、合作計畫及適用對象。
4. 按「新增學期」。

同一合作計畫的啟用期間不能重疊。不同合作計畫可以設定不同期間，學期數量不設上限。

### 7.2 編輯學期

1. 找到要修改的學期卡片。
2. 點右側鉛筆圖示。
3. 修改名稱、日期、合作計畫或適用對象。
4. 按「儲存修改」。

修改日期會立即影響補登截止日及證明下載開放時間，系統不會自動把既有課程移回新日期範圍。若學期已開始或已有課程，修改前請先確認影響範圍。

### 7.3 刪除或移除設定

- 尚未建立配對的學期：可直接刪除。
- 已有配對或課程的學期：不可刪除歷史資料。
- 已結束且已有資料的學期：只能移除設定或封存，歷史課程與時數仍會保留。

## 八、口語能力證明審核

老師須通過口語能力證明審核，才可以瀏覽學生及發出邀請。

### 8.1 查看文件

1. 點左側「口語能力審核」。
2. 找到待審核老師。
3. 點檔名開啟文件。
4. 核對姓名、文件內容及是否符合系辦規定。

資格文件包含個資，只能在管理用途下開啟，不要另存到公用電腦或轉傳到未授權空間。

### 8.2 要求補件

1. 在審核備註寫清楚需補件的原因，例如檔案模糊、內容不完整或文件類型不符。
2. 按「補件」。
3. 老師重新上傳後，該筆資料會再次進入待審核狀態。

補件原因會顯示給老師，請使用能直接理解及修改的文字，不要只寫「不符合」或「請重傳」。

### 8.3 審核通過

1. 確認文件符合規定。
2. 如有需要，在備註欄留下說明。
3. 按「通過」。

通過後，老師會依所屬計畫取得尋找學生及發出邀請的權限。

## 九、邀請與配對管理

### 9.1 查看邀請

「配對管理」會顯示尚待回覆的邀請及近期配對。每筆邀請可查看老師、學生、所屬計畫、學期、邀請方向及到期時間。

邀請送出後保留 5 天。雙方同意後立即成立配對，不需要管理員逐筆核准；過期或取消的邀請不會建立配對。

### 9.2 查看已成立配對

配對成立後，雙方可以查看對方完整資料、使用私訊及安排課程。管理員可在配對管理或行政檔案查看目前及歷史配對。

一般 NTNU 老師同一學期最多配對兩位學生；一般學生同一時間只能有一位老師。系統會依合作計畫及名額規則自動阻擋不符合的組合。

### 9.3 管理員手動配對

此功能供合作計畫或特殊行政安排使用，不需要雙方先送邀請。

1. 在「配對管理」展開「Admin 手動配對」。
2. 選擇老師。
3. 選擇學生。
4. 選擇學期或期間。
5. 按「建立配對」。

建立前，系統仍會檢查角色、帳號狀態、合作計畫資格、學生是否已有老師及是否重複配對。一般 NTNU 計畫仍維持兩位學生上限；只有符合規則的非 NTNU 計畫，才可由管理員建立第三位學生。

### 9.4 建立失敗時

畫面會顯示阻擋原因，例如：

- 老師或學生不屬於該合作計畫。
- 學生已有進行中的配對。
- 同一組本學期已配對過。
- 老師已達名額上限。
- 帳號已停用。

請先修正名冊或配對狀態，不要為了建立配對而任意更改合作計畫。

## 十、解除配對審核

### 10.1 查看申請

1. 點左側「解除審核」。
2. 查看申請人、配對對象、解除原因、補充說明及提出時間。
3. 必要時先查閱雙方課程、私訊、課堂通報及異常回報。

### 10.2 核准或拒絕

- 核准：配對結束，雙方同一學期不能再次配對彼此；歷史課程、有效時數及私訊紀錄保留。
- 拒絕：配對維持，審核結果及備註保留。

未出席、失去聯絡或時間無法配合等原因，管理員 48 小時未處理時，系統可依規則自動解除。態度、行為或其他原因仍須由管理員判斷，不會自動核准。

---

## 十一、全系課程總覽

### 11.1 篩選課程資料

1. 點左側「課程總覽」。
2. 選擇學期。
3. 視需要輸入老師姓名或學號。
4. 選擇「全部老師」或「有未完成課程」。
5. 按「套用」。

頁面會顯示老師人數、課程總數、已排時數、有效時數及未完成課程數。

### 11.2 尚未完成的課程

展開「尚未完成的課程」，可查看缺少簽到、課堂紀錄或互相確認的課程。這個區段用來掌握進度，不代表每筆都需要管理員處理。

只有逾期補簽到或補課堂紀錄，才會在雙方完成確認後進入「補登審核」。

### 11.3 查看老師個人課表

1. 在老師名單找到指定老師。
2. 點「查看課表」。
3. 分別展開即將與未來課程、過去課程。
4. 點單堂課可查看雙方簽到、紀錄、佐證連結、互認、通報及異常回報。

管理員只能查閱，不能代替老師或學生簽到、填寫紀錄或完成互認。

---

## 十二、課堂通報與異常回報

### 12.1 課堂通報

課堂通報只能在上課時間內由老師或學生送出，適用於當下聯絡不到對方、未出席或其他需要立即留下紀錄的情況。

處理方式：

1. 點左側「課堂通報」。
2. 開啟待處理資料。
3. 查閱課程、通報人及內容。
4. 填寫管理員備註。
5. 按「標記已紀錄」。

使用者可在管理員處理前取消通報。取消後不再列為待處理。標記「已紀錄」表示管理員已知悉並保存資料，不代表事件已完全解決。

### 12.2 異常回報

異常回報用於課後提出場地、進度、態度、行為或安全等問題。

1. 點左側「異常回報」。
2. 查看回報類別、內容、課程及雙方資料。
3. 視需要查閱課程紀錄與佐證連結。
4. 填寫管理員備註。
5. 按「標記已紀錄」。

管理員備註會保留在系統中。涉及人身安全、騷擾或其他重大事件時，請依系辦既有行政程序另外通報，不要只在系統按「已紀錄」。

---

## 十三、補登審核

逾期補簽到或補課堂紀錄，須由雙方完成內容及互相確認，再由管理員逐筆核准，才能計入有效時數。

### 13.1 查看待審資料

1. 點左側「補登審核」。
2. 依「補簽到」或「補課堂紀錄」展開對應區段。
3. 點「查看簽到與課堂紀錄」。
4. 核對雙方簽到、課堂紀錄、佐證連結、補登原因及互相確認狀態。

### 13.2 審核原則

核准前至少確認：

- 課程確實屬於該組配對及學期。
- 雙方已完成必要內容。
- 雙方已互相確認。
- 補登原因合理且已填寫。
- 佐證連結可由管理員開啟，內容與當次課程有關。

系統不會自動判斷 Google Drive、YouTube 或其他外部連結是否失效。若連結無法開啟，請先確認分享權限；仍無法查核時，可不核准並在備註說明原因。

### 13.3 核准或不核准

- 核准：該堂課完成補登並計入有效時數。
- 不核准：該堂課不計入有效時數，畫面保留審核人、時間及備註。

已處理項目會依類別及結果保留在歷史區，不能重複審核。補簽到與補課堂紀錄的每學期使用次數由系統分開計算及限制。

---

## 十四、時數調整紀錄

此功能用於補登系統上線前的紙本時數，或經系辦確認的行政更正，不用來修改一般課程時數。

### 14.1 新增時數調整

1. 進入系統管理後台的「時數調整紀錄」。
2. 選擇使用者、合作計畫及適用期間。
3. 輸入增加時數。
4. 填寫具體原因及依據。
5. 儲存。

時數調整只能增加，不能輸入負數。新增後會更新使用者總時數及證明時數，但不會建立一堂不存在的課程。

### 14.2 查閱紀錄

每筆紀錄會保留使用者、計畫、時數、原因、建立人及建立時間。若發現輸入錯誤，先停止後續證明下載，再交由維運人員確認修正方式，不要另建一筆內容不明的資料抵銷。

## 十五、資料匯出

資料匯出依序分成五個步驟。

### 15.1 選擇計畫

先選要匯出的合作計畫。後續使用者及學期選項會跟著更新。

### 15.2 選擇對象

- 老師：匯出所選計畫適用的老師。
- 學生：匯出所選計畫的學生。
- 特定使用者：展開名單後搜尋並勾選一位或多位使用者。

切換老師或學生時，下方名單會同步變更。送出前請再次確認已選人數。

### 15.3 選擇時間

- 選擇學期：從所選計畫的學期清單選擇。
- 自訂時間段：填寫開始日及結束日。

結束日不得早於開始日。若所選計畫沒有可用學期，請先到「學期設定」新增期間，或改用自訂日期。

### 15.4 選擇欄位

可勾選學號、中文姓名、英文姓名、身分、學期、日期、時間、時數、對方學號、輔導對象及狀態。使用「全選」或「清除」後，也要確認已選欄位數量。

### 15.5 選擇格式並下載

| 格式 | 適用情況 |
| --- | --- |
| Excel `.xlsx` | 一般行政整理，建議優先使用 |
| CSV `.csv` | 匯入其他系統或進一步資料處理 |
| PDF `.pdf` | 列印、會議或固定版面存檔 |

按「匯出資料」後，實際開啟檔案確認中文、筆數、時間範圍及欄位正確。

匯出檔案可能含學號、姓名及課程紀錄。使用完畢後請移至系辦核准的儲存位置，不要放在公開雲端、個人裝置下載資料夾或通訊群組。

## 十六、系統紀錄

### 16.1 查看近期操作

點左側「系統紀錄」，可查看近期註冊、個人資料修改、口語能力審核、配對、解除、補登、時數調整及其他行政操作。

每筆紀錄會顯示操作時間、事件、對象及結果。系統紀錄不應顯示密碼、安全問題答案或文件內容。

### 16.2 查核問題時要記錄什麼

若需請維運人員協助，請提供：

1. 發生日期及時間。
2. 操作的管理員帳號。
3. 相關學號、配對或課程。
4. 點擊的功能及按鈕。
5. 畫面錯誤訊息。
6. 已遮住密碼、安全問題答案及非必要個資的截圖。

不要自行刪除系統紀錄，也不要直接修改資料庫。

## 十七、例行行政檢查

### 17.1 每週建議檢查

- 待審核口語能力證明。
- 待處理解除配對申請。
- 課堂通報及異常回報。
- 待審核補登資料。
- 未完成課程數量是否異常增加。

### 17.2 每學期開始前

- 確認合作計畫及學期日期。
- 匯入正確的老師及學生名冊。
- 確認合作計畫邀請權限及上課文件。
- 確認管理員帳號仍由現任承辦人使用。

### 17.3 每學期結束後

- 確認補登期限及證明下載開放日。
- 檢查未完成課程、補登與異常事件。
- 匯出需要留存的行政資料。
- 確認使用者仍可查看歷史課程、時數及私訊。
- 依系辦規定停用離校或不再參與計畫的帳號。

### 17.4 不要自行處理的項目

以下情況請交由維運人員處理：

- 新增或刪除管理員帳號。
- 重設管理員密碼。
- 大量刪除名冊、帳號、配對、課程或訊息。
- 直接修改資料庫。
- 畫面顯示英文錯誤訊息或空白頁面、無法正常操作，或資料消失、權限錯置。
- 證明姓名、計畫或時數明顯屬於其他人。
- 備份還原、版本更新、弱點掃描或伺服器設定。

## 十八、問題回報格式

發現問題時，請用以下格式提供資訊：

```text
發生時間：
使用帳號：
功能名稱：
相關學號／課程：
操作步驟：
實際看到的結果：
原本預期的結果：
裝置及瀏覽器：
```

截圖前請遮住密碼、安全問題答案及與問題無關的個資。若問題涉及看見他人資料、錯誤計算時數、錯誤產生證明或無法登入，請立即通知維運人員，不要繼續操作。
