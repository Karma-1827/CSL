# MPTS 學生操作手冊

本手冊提供 MPTS 學生使用，內容包含帳號註冊、老師配對、查看課表、簽到、課堂紀錄、補登、解除配對及證明下載等日常操作。

正式系統網址：[https://mpts.tcsl.ntnu.edu.tw/](https://mpts.tcsl.ntnu.edu.tw/)

---

## 一、使用前先了解

### 1.1 適用對象

本手冊中的「學生」是指系統畫面顯示為「學生 / Student」的使用者，包括師大外籍生、馬里蘭大學學生及其他合作計畫學生。

各計畫的媒合方式、上課文件與證明名稱不完全相同。畫面沒有出現某個選單時，通常代表該帳號所屬計畫不使用該功能，不一定是系統故障。

### 1.2 開始前請準備

- 系辦提供或確認過的學號。
- 名冊上的身分別，例如本地生、僑生、港澳生、陸生、外籍生或馬里蘭學生。
- 可正常收信的 Email。
- 自己能記住的三組安全問題與答案。
- 自己的華語程度、學習需求及可上課時間。

學號與身分別必須和系辦匯入的名冊一致，否則無法註冊。英文字母大小寫不影響學號辨識，但仍建議依正式學號格式輸入。

### 1.3 個資與帳號安全

- 不要共用帳號或密碼。
- 不要把密碼及安全問題答案傳給他人。
- 使用公用電腦後務必登出並關閉瀏覽器。
- 課堂佐證連結只開放給配對老師與管理人員查看，不要設為公開搜尋。

## 二、第一次註冊

### 2.1 開啟註冊頁

1. 開啟正式系統首頁。
2. 按「我要註冊 / Register」。
3. 選擇「學生 / Student」。

![學生帳號註冊頁](../mpts步驟截圖/student_guide/s-2.1.png)

### 2.2 建立帳號

1. 輸入學號。
2. 選擇與名冊相同的身分別。
3. 設定至少 10 個字元的密碼。
4. 再輸入一次相同密碼。
5. 按「註冊並填寫個人資料 / Register and continue」。

如果系統顯示資料不符，先檢查學號及身分別。仍無法註冊時，請將學號、選擇的身分別及錯誤畫面交給管理員確認名冊，不要反覆嘗試不同身分別。

### 2.3 確認名冊資料

系統會顯示學號、角色與計畫資料。確認角色為「學生 / Student」且資料正確後再繼續；若資料錯誤，請停止註冊並聯絡管理員。

### 2.4 填寫個人與學習資料

依畫面欄位填寫或選擇資料。必填欄位未完成時，系統會在欄位附近顯示提示。

填寫時請注意：

- 英文姓名為必填；沒有中文姓名時可留空。
- 姓名請使用正式資料，不要填暱稱。
- Email 請填可正常收信的信箱。
- 華語程度、想加強的項目與可上課時間會顯示在匿名媒合資料中，請依實際情況填寫。

### 2.5 設定安全問題

1. 選擇三個不同的安全問題；已選過的問題不能重複選擇。
2. 每題填寫至少 3 個字元的答案。
3. 記住答案的文字、空格與寫法，忘記密碼時會用來驗證身分。

安全問題答案不應使用密碼，也不要選擇別人容易從社群網站猜到的內容。

### 2.6 完成註冊

確認個人資料、學習資料、安全問題及可上課時間後，勾選同意事項並送出。註冊完成後會直接進入學生使用介面。

## 三、登入、登出與忘記密碼

### 3.1 登入

1. 開啟正式系統首頁。
2. 輸入學號及密碼。
3. 按「登入 / Sign in」。

若登入失敗，先確認鍵盤大小寫及密碼。連續輸入錯誤時，系統可能暫時限制登入，請稍後再試，不要持續重複送出。

### 3.2 登出

按右上角「登出 / Sign out」。確認回到登入頁後再關閉瀏覽器。

### 3.3 忘記密碼

1. 在登入頁按「忘記密碼 / Forgot password」。
2. 輸入學號並繼續。
3. 回答註冊時設定的三個安全問題。
4. 驗證成功後設定新密碼，並再次輸入確認。
5. 回到登入頁，以新密碼登入。

系統不會顯示原密碼。若忘記安全問題答案，請聯絡管理員處理，不要將可能的答案交給他人代試。

登入後，左側功能選單是主要操作入口。

| 功能 | 用途 |

| 我的課表 | 查看老師建立的課程、課程狀態及進入課堂頁 |

## 五、老師配對

### 5.1 一般學生：收到老師邀請

一般師大外籍生不需要主動尋找老師。老師送出邀請後：

1. 按左側「邀請管理 / Invitations」。
2. 查看收到的老師邀請與匿名資料。
3. 選擇接受或婉拒。

接受後配對立即成立，雙方才會看到姓名、學號及 Email。一位學生同一學期只能有 1 位進行中的老師；配對成立後，其他尚未完成的相關邀請會由系統取消。

### 5.2 馬里蘭計畫學生：尋找老師

馬里蘭計畫學生可主動尋找老師：

1. 按「尋找老師 / Find teachers」。
2. 查看老師的匿名資料與可上課時間。
3. 使用搜尋條件縮小結果。
4. 選擇老師並按「邀請老師 / Invite teacher」。
5. 到「邀請管理」查看等待回覆狀態。

![尋找老師頁](../mpts步驟截圖/student_guide/s-5.1.png)

學生只會看到自己計畫可配對的老師。配對成立前，系統不會顯示老師姓名、學號及 Email。

### 5.3 邀請期限與取消

- 邀請有效期限為 5 天。
- 每位使用者同一學期最多同時有 3 筆待回覆邀請。
- 同一組已有待回覆邀請時，不能重複送出。
- 發起邀請的人可在對方回覆前取消邀請。

### 5.4 配對成立後

回到「我的首頁」，在「我的配對」查看老師。點「查看資料 / View profile」可查看配對後開放的基本資料。

## 六、私訊與解除配對

### 6.1 使用私訊

1. 按左側「私訊 / Messages」，或在配對卡片按「私訊 / Message」。
2. 選擇老師。
3. 輸入訊息並送出。

私訊適合確認上課時間、地點與一般課務事項。緊急事件或安全問題不要只留在私訊中，應另外聯絡管理員。

### 6.2 申請解除配對

在配對卡片找到「解除配對 / Release pairing」，選擇原因並送出。

- 未出席、失去聯絡或時間無法配合：管理員 48 小時內未處理時，系統會自動解除。
- 態度或行為問題、其他原因：必須填寫說明，並等待管理員審核。

申請送出後，在系統顯示配對已解除前，請不要自行假設配對已經終止。解除後，已建立的歷史課程與訊息仍會保留供查閱。

## 七、查看課表與課程異動

### 7.1 查看老師建立的課程

按「我的課表 / Schedule」，可查看日期、時間、老師及課程狀態。點「查看課程 / View」可進入該堂課。

![學生課表](../mpts步驟截圖/student_guide/s-8.1.png)

課程只能由老師建立、修改或取消。學生不能直接改動課表。

### 7.2 時間有誤或無法上課

使用私訊聯絡老師，請老師修改或取消。老師完成後，再回到「我的課表」確認變更。

若課程已經有簽到或課堂紀錄，老師也不能自行修改或取消，雙方應聯絡管理員處理。

## 八、上課當天：簽到與課堂紀錄

### 8.1 進入課堂頁

從「我的首頁」或「我的課表」找到課程，按「查看課程 / View」。課堂頁會依序顯示雙方簽到、課堂紀錄、互相確認及審核狀態。

### 8.2 簽到

- 上課前 10 分鐘開始開放簽到。
- 課程結束後 30 分鐘內仍屬一般簽到。
- 超過課程結束 30 分鐘才簽到，會改為補簽到，必須填寫原因。

按「確認簽到 / Check in」後，確認畫面顯示已完成簽到。老師與學生都要使用自己的帳號簽到，不能由一方代簽。

### 8.3 課堂進行中通報

上課期間若老師未出席或無法聯絡，可在課堂頁使用即時通報。這項功能只在課程進行時間內開放，送出後管理員會看到通報紀錄。

若涉及人身安全或緊急事件，請先使用校方或緊急聯絡方式處理，不要等待系統回覆。

### 8.4 填寫學生課堂紀錄

課程開始後即可填寫。依畫面完成上課地點、學習內容、教材、個別學習情形及心得等欄位。畫面會顯示字數計數，請勿超過欄位上限。

學生可選擇提供 0–5 個 `https://` 佐證連結，例如上課畫面截圖、教材、作業或錄影。若提供連結：

1. 開啟共用檢視權限，讓老師與管理員可以直接查看。
2. 不要分享密碼或設定需要另外申請權限的連結。
3. 保留至本次實習或輔導階段結束後至少 10 天。

![學生課堂紀錄頁](../mpts步驟截圖/student_guide/s-9.4.png)

### 8.5 確認老師資料

老師完成簽到與課堂紀錄後，學生可查看並選擇：

- 資料正確：確認老師的簽到與紀錄。
- 需要修改：填寫原因，請老師修正。
- 回報問題：填寫問題內容，交由管理員查看。

老師修改紀錄後，原確認會失效，學生需要重新檢查及確認。

### 8.6 有效時數成立條件

一堂課必須同時符合下列條件，才會列入有效紀錄與時數：

1. 老師與學生都完成簽到。
2. 老師與學生都提交課堂紀錄。
3. 雙方都確認對方的簽到與紀錄。
4. 若有補簽到或補課堂紀錄，管理員已核准補登。

只完成單方資料、仍待對方確認或補登未核准，都不會列入有效紀錄與時數。

## 九、補簽到與補課堂紀錄

### 9.1 什麼情況會成為補登

| 操作 | 一般期限 | 超過後 |
| --- | --- | --- |
| 簽到 | 課程結束後 30 分鐘內 | 成為補簽到，需填原因 |
| 課堂紀錄 | 課程結束後 24 小時內 | 新增時成為補課堂紀錄，需填原因 |

補登最後期限以課堂頁顯示為準；超過該學期補登期限後，系統不再接受補登。

### 9.2 補登次數

每位使用者每學期最多：

- 補簽到 5 次。
- 補課堂紀錄 5 次。

兩種次數分開計算。

### 9.3 補登流程

1. 從「輔導紀錄」找到過去課程，按「查看課程」。
2. 完成補簽到或補課堂紀錄並填寫原因。
3. 等待老師完成資料與互相確認。
4. 雙方確認完成後，等待管理員審核。
5. 回到「輔導紀錄」查看結果。

狀態顯示「未核准 / Rejected」時，該堂不列入有效紀錄與時數。若認為結果有誤，請提供課程日期、配對老師及畫面給管理員查核，不要重複送出不同內容。

## 十、輔導紀錄與證明

### 10.1 查看輔導紀錄

按左側「輔導紀錄 / History」。頁面會列出課程及狀態，例如有效成立、待完成、待審核或未核准。

![輔導紀錄頁](../mpts步驟截圖/student_guide/s-12.1.png)

若總時數與預期不同，先逐堂檢查雙方是否完成簽到、紀錄及確認；有補登時再確認管理員是否已核准。

### 10.2 預覽與下載證明

所屬計畫開放學生下載證明時，可在下載區：

1. 選擇學期，或自訂日期範圍。
2. 選擇中文或英文。
3. 選擇摘要版或詳細版；詳細版可再選擇要顯示的欄位。
4. 先按預覽確認內容，再下載 PDF。

目前學期的證明會在學期結束後第 3 天開放下載。過去學期若已有有效時數，可依頁面提供的期間下載。

證明名稱依合作計畫不同：

- 師大外籍生計畫：受輔導證明。
- 馬里蘭計畫：語言交換證明。
- 其他合作計畫：依該計畫設定顯示。

![學生證明下載區](../mpts步驟截圖/student_guide/s-12.2.png)

### 10.3 證明資料錯誤

若姓名、學號、計畫、日期或時數有誤，不要自行修改 PDF。請先確認個人資料與課程狀態，再將錯誤項目、課程日期及畫面交給管理員查核。

## 十一、合作計畫上課文件

只有所屬計畫已啟用此功能時，網站上方才會顯示「上課文件 / Class documents」。目前主要提供馬里蘭計畫使用。

1. 點網站上方「上課文件」。
2. 查看文件名稱、適用計畫及學期。
3. 按下載並依文件內容上課。

![合作計畫上課文件頁](../mpts步驟截圖/student_guide/s-12.3.png)

文件只能供計畫內部使用，不要轉傳至公開網站或不相關的人員。

## 十二、常見問題

### 12.1 看不到「尋找老師」

這個功能只開放給允許學生主動媒合的合作計畫，目前主要適用於馬里蘭計畫。一般師大外籍生由老師主動邀請，請到「邀請管理」查看收到的邀請。

### 12.2 已配對後不能再找老師

一位學生同一學期只能有 1 位進行中的老師。已建立配對時，系統會顯示目前不需要尋找新老師。

### 12.3 課程時間錯誤，但不能修改

學生不能直接修改課程。請用私訊聯絡老師，由老師修改或取消；若課程已有簽到或紀錄，請聯絡管理員。

### 12.4 課程沒有列入有效紀錄

一堂課需要雙方簽到、雙方課堂紀錄、雙方互相確認；補登還要經管理員核准。任何一項未完成，都不會列入有效紀錄與時數。

### 12.5 頁面顯示 CSRF 驗證失敗

這通常是頁面開啟太久，或在另一個分頁重新登入後，舊頁面的安全驗證已失效。重新整理頁面，再從系統內重新操作；不要重複送出舊分頁中的表單。

### 12.6 聯絡管理員時要提供什麼

請提供：

- 學號。
- 發生日期與時間。
- 使用的功能與操作步驟。
- 畫面上的完整錯誤訊息。
- 不含密碼、安全問題答案的畫面截圖。

不要在訊息或截圖中附上密碼及安全問題答案。
