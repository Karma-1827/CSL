# SECURITY_CHECKLIST.md

本文件是師大資訊中心「資通系統防護基準檢核表」(附件二,115 新表格)**中級**版本的先期草稿,逐條對照 CSL 系統目前的實際狀況。目的是讓 V4「正式上線與行政營運」有一份具體、可執行的清單,也讓之後系辦/資訊中心要送件時,有現成的底稿可以核對、補件。

> 依據文件(使用者提供,存放於 `學校文件/` 目錄,未納入版本控制):
> - `附件一_資通系統安全等級評估表.docx`(安全等級評估表與範例)
> - `附件二_資通系統防護基準檢核表(115新表格及範本).xlsx`(本文件對照的來源,取用其中「中級」分頁)
> - `附件三_資訊系統清冊(115新表格).xlsx`(系統清冊填表說明與驗證項目代碼)
> - `UP03_VM_rule.pdf`(師大資訊中心虛擬主機服務管理暨收費辦法)
> - `rent_VM_notice.pdf`(虛擬伺服器申請注意事項)
>
> 盤點日期:2026-07-26。**下列「等級」是我方初估,不是系辦核定結果**,正式等級仍須依附件一送系辦/資訊中心確認。

## 安全等級初估

依附件一四構面評估法初估:

| 構面 | 初估等級 | 理由 |
| --- | --- | --- |
| 機密性 | 中 | 名冊、Profile、資格文件、課堂紀錄附件含個資,但非身分證字號等特種個資或財務資料 |
| 完整性 | 中 | 時數證明直接影響研究生畢業門檻,資料遭竄改後果不小 |
| 可用性 | 普 | 可容忍中斷超過 24 小時,無即時性要求 |
| 法律遵循性 | 中 | 涉及約 500–600 人個資,須依個資法辦理,但資料量與敏感度未達高標準門檻 |

**綜合初估:中**(類似附件一範例中的「人事管理系統」)。下表即依「中級」檢核表逐條列出。
