# MPTS 老師操作手冊

本手冊提供 MPTS 老師使用，內容包含帳號註冊、口語能力證明、學生配對、排課、簽到、課堂紀錄、補登、解除配對及時數證明等日常操作。

正式系統網址：[https://mpts.tcsl.ntnu.edu.tw/](https://mpts.tcsl.ntnu.edu.tw/)

---

## 一、使用前先了解

### 1.1 適用對象

本手冊中的「老師」是指系統畫面顯示為「老師 / Teacher」的使用者，包括：

- 參與師大外籍生華語輔導計畫的華語輔導老師。
- 參與馬里蘭大學合作計畫的華語老師。
- 由系辦安排至其他合作計畫的華語老師。

各計畫可使用的媒合、文件及證明功能不完全相同。畫面沒有出現某個選單時，通常代表該帳號所屬計畫不使用該功能，不一定是系統故障。

### 1.2 開始前請準備

- 系辦提供或確認過的學號。
- 名冊上的身分別，例如本地生、僑生、港澳生、陸生、外籍生或馬里蘭學生。
- 可正常收信的 Email。
- 口語能力證明檔案，格式依上傳頁說明辦理。
- 自己能記住的三組安全問題與答案。

學號與身分別必須和系辦匯入的名冊一致，否則無法註冊。英文字母大小寫不影響學號辨識，但仍建議依正式學號格式輸入。

### 1.3 個資與帳號安全

- 不要共用帳號或密碼。
- 不要把密碼、安全問題答案或未公開的學生資料傳給他人。
- 使用公用電腦後務必登出並關閉瀏覽器。
- 課堂佐證連結只開放給配對對象與管理人員查看，不要設為公開搜尋。

## 二、第一次註冊

### 2.1 開啟註冊頁

1. 開啟正式系統首頁。
2. 按「我要註冊 / Register」。
3. 選擇「老師 / Teacher」。

![老師帳號註冊頁](../mpts步驟截圖/teacher_guide/t-2.1.png)

### 2.2 建立帳號

1. 輸入學號。
2. 選擇與名冊相同的身分別。
3. 設定至少 10 個字元的密碼。
4. 再輸入一次相同密碼。
5. 按「註冊並填寫個人資料 / Register and continue」。

如果系統顯示資料不符，先檢查學號及身分別。仍無法註冊時，請將學號、選擇的身分別及錯誤畫面交給管理員確認名冊，不要反覆嘗試不同身分別。

### 2.3 確認名冊資料

系統會顯示學號與角色。確認資料正確後繼續填寫；若角色不是「老師 / Teacher」，請停止註冊並聯絡管理員。

### 2.4 填寫個人與教學資料

依畫面欄位填寫或選擇資料。必填欄位未完成時，系統會在欄位附近顯示提示。

填寫時請注意：

- 姓名請使用正式資料，不要填暱稱。
- Email 請填可正常收信的信箱。
- 教學能力評估請依自己的實際情況選擇。
- 可上課時間會顯示在匿名媒合資料中，請填寫真正能配合的時段。

### 2.5 設定安全問題

1. 選擇三個不同的安全問題；已選過的問題不能重複選擇。
2. 每題填寫至少 3 個字元的答案。
3. 記住答案的文字、空格與寫法，忘記密碼時會用來驗證身分。

安全問題答案不應使用密碼，也不要選擇別人容易從社群網站猜到的內容。

### 2.6 上傳口語能力證明

依畫面說明選擇檔案並上傳。完成註冊後，文件會進入管理員審核流程；審核通過前仍可登入及查看資料，但不能開始尋找學生。

### 2.7 完成註冊

確認個人資料、教學資料、安全問題、口語能力證明及可上課時間後，勾選同意事項並送出。註冊完成後會直接進入老師使用介面。

## 三、登入、登出與忘記密碼

### 3.1 登入

1. 開啟正式系統首頁。
2. 輸入學號及密碼。
3. 按「登入 / Sign in」。

若登入失敗，先確認鍵盤大小寫及密碼。連續輸入錯誤時，系統可能暫時限制登入，請稍後再試，不要持續重複送出。

### 3.2 登出

按右上角「登出 / Sign out」。確認回到登入頁後再關閉瀏覽器。

### 3.3 忘記密碼

1. 在登入頁按「忘記密碼 / Forgot password」。
2. 輸入學號並繼續。
3. 回答註冊時設定的三個安全問題。
4. 驗證成功後設定新密碼，並再次輸入確認。
5. 回到登入頁，以新密碼登入。

系統不會顯示原密碼。若忘記安全問題答案，請聯絡管理員處理，不要將可能的答案交給他人代試。

## 五、口語能力證明

### 5.1 查看審核狀態

按左側「口語能力證明 / Oral proficiency」。常見狀態如下：

| 狀態 | 代表意義 | 下一步 |
| --- | --- | --- |
| 待審核 | 文件已送出，管理員尚未完成審核 | 等待審核 |
| 已通過 | 文件符合規定 | 可進行學生媒合 |
| 需補件／未通過 | 文件或內容需要修正 | 查看審核意見後重新上傳 |

![口語能力證明頁](../mpts步驟截圖/teacher_guide/t-5.1.png)

### 5.2 重新送審

1. 查看管理員留下的審核說明。
2. 依說明準備正確檔案。
3. 選擇新檔案。
4. 按「重新送審 / Resubmit」。

重新送出後狀態會回到待審核。審核標準與可接受文件，以頁面說明及管理員通知為準。

## 六、尋找學生與邀請配對

### 6.1 開放條件

老師須同時符合以下條件，才會看到可邀請的學生：

- 已完成註冊及個人資料。
- 口語能力證明已通過。
- 目前計畫及學期已開放媒合。
- 尚有配對名額。

若畫面沒有學生，可能是目前沒有符合條件且尚未配對的學生，不代表系統一定有問題。

### 6.2 查看匿名學生資料

按「尋找學生 / Find students」。配對成立前，系統只顯示學習需求、程度、語言、可上課時間等媒合資料，不顯示姓名、學號及 Email。

![尋找學生頁](../mpts步驟截圖/teacher_guide/t-6.1.png)

老師只能看到自己可服務計畫中的學生：

- 一般華語輔導老師看到師大外籍生計畫的學生。
- 馬里蘭計畫老師看到馬里蘭計畫學生。
- 其他合作計畫依名冊與系統設定顯示。

可按「搜尋條件 / Search filters」縮小結果，例如華語程度、加強項目、性別、母語、日期及時段。

### 6.3 送出邀請

1. 閱讀學生匿名資料。
2. 確認學習需求與時間大致可以配合。
3. 按「邀請學生 / Invite student」。
4. 到「邀請管理」查看等待回覆狀態。

邀請有效期限為 5 天。每位使用者同一學期最多同時有 3 筆待回覆邀請；同一組已有待回覆邀請時，不能重複送出。

### 6.4 取消尚未回覆的邀請

發起邀請的人可在「邀請管理」取消尚未回覆的邀請。取消後若仍有媒合名額，可重新選擇其他對象。

### 6.5 收到學生邀請

只有所屬計畫允許學生主動邀請時，老師才會收到學生送出的邀請；目前主要適用於馬里蘭計畫。

1. 按「邀請管理」。
2. 查看收到的邀請與匿名資料。
3. 選擇接受或婉拒。

接受後配對立即成立，雙方才會看到姓名、學號及 Email。一般自行媒合流程中，一位老師同一學期最多有 2 位進行中的學生；名額已滿時，系統不再接受新的自行媒合邀請。

## 七、配對成立後

### 7.1 查看學生資料

回到「我的首頁」，在「目前配對」查看學生。點「查看資料 / View profile」可查看配對後開放的基本資料。

### 7.2 使用私訊

1. 按左側「私訊 / Messages」，或在配對卡片按「私訊 / Message」。
2. 選擇學生。
3. 輸入訊息並送出。

私訊適合確認上課時間、地點與一般課務事項。緊急事件或安全問題不要只留在私訊中，應另外聯絡管理員。

### 7.3 申請解除配對

在配對卡片找到「解除配對 / Release pairing」，選擇原因並送出。

- 未出席、失去聯絡或時間無法配合：管理員 48 小時內未處理時，系統會自動解除。
- 態度或行為問題、其他原因：必須填寫說明，並等待管理員審核。

申請送出後，在系統顯示配對已解除前，請不要自行假設配對已經終止。解除後，已建立的歷史課程與訊息仍會保留供查閱。

## 八、建立與管理課程

### 8.1 建立單次課程

1. 按「我的課表 / Schedule」。
2. 找到建立課程區塊。
3. 選擇學生、上課日期、開始時間及時數。
4. 按「建立課程 / Create class」。

排課規則：

| 項目 | 系統規則 |
| --- | --- |
| 課程時數 | 0.5、1、1.5 或 2 小時 |
| 開始時間 | 分鐘須為 5 分鐘的倍數 |
| 上課日期 | 必須在該計畫學期內，且新課程須排在未來 |
| 同一組每週 | 最多 2 小時 |
| 同一組每學期 | 最多 32 小時 |
| 老師每學期 | 最多 64 小時 |

![建立課程頁](../mpts步驟截圖/teacher_guide/t-9.1.png)

### 8.2 建立每週重複課程

建立課程時勾選「每週重複 / Repeat weekly」，再選擇重複結束日。系統會逐週建立課程，直到指定日期或學期結束日；只要其中一堂超過時數上限，整次建立就不會完成。

### 8.3 修改課程

1. 在課表點「查看課程 / View class」。
2. 往下找到修改區塊。
3. 選擇新日期、時間及時數。
4. 重複課程可選擇只修改本堂，或修改本堂及之後的課程。
5. 儲存後回到課表確認變更。

修改後的課程必須在未來、學期期間內，且仍符合每週與每學期時數限制。課程已有簽到或紀錄時不能自行修改；課程結束超過 3 週也不能修改，需聯絡管理員確認。

### 8.4 取消課程

1. 在課表開啟該堂課。
2. 找到取消課程區塊。
3. 填寫取消原因並送出。
4. 回到課表確認課程狀態。

已有簽到或課堂紀錄的課程不能自行取消；課程結束超過 3 週也不能取消。

## 九、上課當天：簽到與課堂紀錄

### 9.1 進入課堂頁

從「我的首頁」或「我的課表」找到課程，按「查看課程 / View」。課堂頁會依序顯示雙方簽到、課堂紀錄、互相確認及審核狀態。

### 9.2 簽到

- 上課前 10 分鐘開始開放簽到。
- 課程結束後 30 分鐘內仍屬一般簽到。
- 超過課程結束 30 分鐘才簽到，會改為補簽到，必須填寫原因。

按「確認簽到 / Check in」後，確認畫面顯示已完成簽到。老師與學生都要使用自己的帳號簽到，不能由一方代簽。

### 9.3 課堂進行中通報

上課期間若對方未出席或無法聯絡，可在課堂頁使用即時通報。這項功能只在課程進行時間內開放，送出後管理員會看到通報紀錄。

若涉及人身安全或緊急事件，請先使用校方或緊急聯絡方式處理，不要等待系統回覆。

### 9.4 填寫老師課堂紀錄

課程開始後即可填寫。依畫面完成上課地點、教學目標、教學範圍與流程、教材、個別學習情形及心得等欄位。畫面會顯示字數計數，請勿超過欄位上限。

老師每堂課必須提供 1–5 個 `https://` 佐證連結，例如：

- 上課畫面截圖
- 教材或簡報
- 作業或學習紀錄
- 上課錄影

請確認連結已開啟共用檢視權限，讓學生與管理員可以直接查看。佐證資料應保留至本次實習或輔導階段結束後至少 10 天；查核時無法開啟，該堂時數可能不予採計。

![老師課堂紀錄頁](../mpts步驟截圖/teacher_guide/t-10.4.png)

### 9.5 確認學生資料

學生完成簽到與課堂紀錄後，老師可查看並選擇：

- 資料正確：確認學生的簽到與紀錄。
- 需要修改：填寫原因，請學生修正。
- 回報問題：填寫問題內容，交由管理員查看。

學生修改紀錄後，原確認會失效，老師需要重新檢查及確認。

### 9.6 有效時數成立條件

一堂課必須同時符合下列條件，才會列入有效時數：

1. 老師與學生都完成簽到。
2. 老師與學生都提交課堂紀錄。
3. 雙方都確認對方的簽到與紀錄。
4. 若有補簽到或補課堂紀錄，管理員已核准補登。

只完成單方資料、仍待對方確認或補登未核准，都不會列入有效時數。

## 十、補簽到與補課堂紀錄

### 10.1 什麼情況會成為補登

| 操作 | 一般期限 | 超過後 |
| --- | --- | --- |
| 簽到 | 課程結束後 30 分鐘內 | 成為補簽到，需填原因 |
| 課堂紀錄 | 課程結束後 24 小時內 | 新增時成為補課堂紀錄，需填原因 |

補登最後期限以課堂頁顯示為準；超過該學期補登期限後，系統不再接受補登。

### 10.2 補登次數

每位使用者每學期最多：

- 補簽到 5 次。
- 補課堂紀錄 5 次。

兩種次數分開計算。

### 10.3 補登流程

1. 從「輔導時數」找到過去課程，按「查看課程」。
2. 完成補簽到或補課堂紀錄並填寫原因。
3. 等待對方完成資料與互相確認。
4. 雙方確認完成後，等待管理員審核。
5. 回到「輔導時數」查看結果。

狀態顯示「未核准 / Rejected」時，該堂不列入有效時數。若認為結果有誤，請提供課程日期、配對對象及畫面給管理員查核，不要重複送出不同內容。

## 十一、輔導時數與證明

### 11.1 查看時數

按左側「輔導時數 / Hours」。頁面會列出課程及狀態，例如有效成立、待完成、待審核或未核准。

![輔導時數頁](../mpts步驟截圖/teacher_guide/t-13.1.png)

若總時數與預期不同，先逐堂檢查雙方是否完成簽到、紀錄及確認；有補登時再確認管理員是否已核准。

### 11.2 預覽與下載證明

有有效時數後，可在下載區：

1. 選擇合作計畫。
2. 選擇學期，或自訂日期範圍。
3. 選擇中文或英文。
4. 選擇摘要版或詳細版；詳細版可再選擇要顯示的欄位。
5. 先按預覽確認內容，再下載 PDF。

目前學期的證明會在學期結束後第 3 天開放下載。過去學期若已有有效時數，可依頁面提供的期間下載。證明名稱與內容會依合作計畫不同，例如實習證明或語言交換服務證明。

### 11.3 證明資料錯誤

若姓名、學號、計畫、日期或時數有誤，不要自行修改 PDF。請先確認個人資料與課程狀態，再將錯誤項目、課程日期及畫面交給管理員查核。

## 十二、合作計畫上課文件

只有所屬計畫已啟用此功能時，網站上方才會顯示「上課文件 / Class documents」。目前主要提供馬里蘭計畫使用。

1. 點網站上方「上課文件」。
2. 查看文件名稱、適用計畫及學期。
3. 按下載並依文件內容上課。

文件只能供計畫內部使用，不要轉傳至公開網站或不相關的人員。

## 十三、常見問題

### 13.1 看不到「尋找學生」或沒有學生卡片

依序確認：

1. 口語能力證明是否已通過。
2. 目前是否有開放中的計畫與學期。
3. 是否已達 2 位進行中學生上限。
4. 是否已有 3 筆待回覆邀請。
5. 目前是否有符合計畫與條件、且尚未配對的學生。

### 13.2 無法修改或取消課程

常見原因包括：課程已有簽到或紀錄、修改後時間不是未來、超過時數上限、日期超出學期，或課程結束已超過 3 週。依畫面錯誤訊息調整；已有課務資料時請聯絡管理員。

### 13.3 課程沒有列入有效時數

一堂課需要雙方簽到、雙方課堂紀錄、雙方互相確認；補登還要經管理員核准。任何一項未完成，都不會列入有效時數。

### 13.4 頁面顯示 CSRF 驗證失敗

這通常是頁面開啟太久，或在另一個分頁重新登入後，舊頁面的安全驗證已失效。重新整理頁面，再從系統內重新操作；不要重複送出舊分頁中的表單。

### 13.5 聯絡管理員時要提供什麼

請提供：

- 學號。
- 發生日期與時間。
- 使用的功能與操作步驟。
- 畫面上的完整錯誤訊息。
- 不含密碼、安全問題答案的畫面截圖。

不要在訊息或截圖中附上密碼及安全問題答案。
